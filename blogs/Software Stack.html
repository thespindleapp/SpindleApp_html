Where the tech sits in fashion production: PLM, ERP, spreadsheets and email

How PLM, ERP, spreadsheets and email fit together in fashion production, which step each one covers, and where the gaps are.

Srishti Dhawan, founder of Spindle
19 Oct 2026

Ask a fashion brand what software it uses and you usually get a list. Design tools, maybe a PLM, an ERP for orders and finance, and a lot of spreadsheets. Ask where the information on one style is right now and the answer is often "in my email".

That is not a failure of the software. Each tool does a real job. The trouble is the space between them. This guide maps the four layers most brands run on and the joins where information gets lost. It also shows how to set up Excel, Trello, Asana and Notion properly, and what Spindle looks like next to them.

The map is general. Brands set things up in very different ways, so treat the coverage as typical, not universal. Use it to see what you need before you buy anything.

Where it stops. Excel holds what you type. It does not read your email, and it won't tell you that two suppliers gave different dates. That is still your job.

Setting up Trello, Asana or Notion

Project tools are good at showing who is doing what, and by when. A style is a long-lived record rather than a task, so the trick is to build the structure around the style. Here is how I would set up each one.

{{ r.k }}{{ r.v }}

Whichever you choose, all three have the same weak point as Excel. They show what someone typed in. A supplier's email changing a quantity does not change the card.

My rough steer: Trello if your team thinks in a visual flow, Notion if you want one database with several views, Asana if the team already lives in it for other work. If you are comfortable in Excel, stay there until the number of styles makes it hard.

Where Spindle fits, and how to choose

Spindle is the colleague that reads what comes in and puts it in one place for the rest of the team. Production runs on email and WhatsApp, so the answer to where a style is sits in someone's inbox or on someone's phone. It is not a PLM and it does not replace one. You forward supplier emails to a Spindle address. Spindle reads them, links each to the right style, and proposes details such as stage, quantity or delivery date. You check each proposal. A production board is then built from the values you have checked, so it reflects what you agreed, not what a program guessed.

It works with the tools you already have. A brand with a PLM can still use it for the emails that never make it into the PLM. A brand with only Excel can use it to stop living in the inbox. At launch you forward emails; a Gmail and Outlook plugin comes later.
